
# Hamasat Kitchenware E-commerce Website

A modern and responsive website developed for **Hamasat Kitchenware Store**,
designed to showcase a wide range of high-quality kitchenware and home products with elegant design and optimized performance.

![Project Showcase](https://raw.githubusercontent.com/Mo-metwally/Images/refs/heads/metwally/Hamasat-ShowCase.webp)

## 🛒 E-commerce Website

A **full-stack E-commerce platform** built with **React (frontend)**, **Node.js + Express (backend)**, and **PostgreSQL (database)**.
The website includes all essential features for managing an online store, except for payment integration (can be added later).

---

## 🚀 Features
- 🖥 **Fully responsive** design (mobile-first, optimized for all devices).
- 🎨 **Modern UI/UX** with smooth navigation and user experience.
- 🔍 **SEO-friendly** (meta tags, Open Graph, structured routing).
- ⚡ **Optimized production build** for fast performance.
- 🔄 **React Query** for caching & managing API calls efficiently.
- 🛠 **Robust backend API** built with **Express.js** and integrated error handling for all operations.
- 🗄 **PostgreSQL database** with structured schema for products, categories, users, and orders.
- 📦 **Admin Dashboard** to manage products, categories, and orders.
- 📱 **PWA Ready** (manifest, service workers, icons, theme color).

---

## 🛠️ Tech Stack
### Frontend:
- **React.js** (v18)
- **React Router DOM (v7)** → For routing & navigation
- **Redux Toolkit** → State management
- **React Query (@tanstack/react-query)** → Server state management & caching API calls
- **Axios** → API requests
- **Material UI (MUI v6)** → UI components
- **Bootstrap 5 / React-Bootstrap** → Styling & layout
- **MDB React UI Kit** → Material Design Bootstrap components
- **Lucide React** → Icons
- **React Icons** → Extended icons library
- **React Slick & Slick Carousel** → Product sliders & carousels
- **Swiper.js** → Advanced touch sliders
- **React Lazy Load Image** → Image optimization & lazy loading
- **React Modal** → Modals handling
- **React Toastify** → Notifications
- **React To Print** → Invoice & reports printing
- **React Quill** → Rich text editor
- **React Select** → Customizable select dropdowns
- **React Scroll** → Smooth scrolling UX


### Backend:
- **Node.js**
- **Express.js** (REST API) with error handling
- **PostgreSQL**
- **Error Handling** Node.js Middleware

### Database:
- **PostgreSQL**
